# BCM 1531, cours 5 en animations

Animations pas à pas du cours 5 de BCM 1531 (Introduction à la biochimie, Université de Montréal) :
correction sur épreuve, terminaison bactérienne, maturation de l'ARNm (coiffe, extrémité 3',
épissage, épissage alternatif), ARN interférence, CRISPR-Cas9 et opéron lac.

Site : https://walthuken.github.io/bcm1531-cours5-animations/

Le fichier `index.html` est généré par `site_cours05.py` à partir des mêmes dessins que les
cartes Anki du cours. Un seul fichier, aucune dépendance.
