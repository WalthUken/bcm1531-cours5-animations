# BCM 1531 en animations

Animations pas à pas de BCM 1531 (Introduction à la biochimie, Université de Montréal) :
enzymes (cours 3), fourche de réplication (cours 4), transcription et maturation de l'ARN
(cours 5), antibiotiques, code génétique et traduction (cours 6). 60 animations, chaque étape expliquée par écrit.

Site : https://walthuken.github.io/bcm1531-cours5-animations/

Le fichier `index.html` est généré par `site_bcm1531.py` à partir des mêmes dessins que les
cartes Anki du cours. Un seul fichier, aucune dépendance.
